amos.bitplane.net

An AMOS Professional interpreter and runtime, reimplemented in TypeScript so old AMOS programs run in a browser. No Amiga ROM, no 68000 emulation — the language and the hardware it drew on are reimplemented from the original 68k source.

Open the player — drop in a .AMOS program, a folder, or a zip.

Versions

/v/latest/ the most recent release, moves under you
/v/<x.y.z>/ one release, immutable — pin this and cache it forever

Versions are paths, not query parameters, so a URL identifies exactly which code runs.

Status

Core AMOS Professional is complete, along with the AMOS 3D, TURBO Plus and LDos extensions. Of a 419-program corpus, 86% run without reaching a single unimplemented keyword. Every place the port knowingly differs from the original is written down in UNIMPLEMENTED.md, split into what can still be fixed and what cannot.
